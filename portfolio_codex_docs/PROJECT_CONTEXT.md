## Flagship project
Indie Game Success Data Engineering Pipeline.

### Overview
An end-to-end pipeline analyzing the commercial success of indie games on Steam.

### Dataset
1,216 indie games derived from 122,611 original Kaggle records.

### Data sources
The pipeline integrates eight sources including:

- Steam data
- Steam Charts scraping
- Google Trends
- Reddit sentiment
- additional metadata sources

### Storage layer
- PostgreSQL
- MongoDB

### Processing layer
- Apache Spark

### Data formats
- Parquet
- DuckDB analytics layer

### Output dataset
Master dataset with approximately 62 features.

### Success tiers
Games are classified into three success tiers based on estimated owners:

- 20k owners
- 200k owners
- 1M owners
