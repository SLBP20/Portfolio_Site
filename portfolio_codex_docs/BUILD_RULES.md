# BUILD_RULES.md

## Engineering rules
- Build with Next.js and Tailwind
- Use reusable components
- Keep the codebase simple and maintainable
- Avoid unnecessary libraries

## UX rules
- Communicate value within 10 seconds
- Projects visible immediately
- Mobile responsive
- Accessible layout

## Content rules
- Do not invent achievements
- Do not exaggerate results
- Use concrete tools and datasets
- Show what Samuel personally built

## Project page structure
Each project should cover:
- problem
- data sources
- architecture
- pipeline / processing
- storage
- analytics outputs
- Samuel’s contribution
- key takeaway

## Styling rules
- minimal animation
- subtle transitions
- spacing over heavy UI components

## Decision rule
If choosing between “looks cool” and “feels credible”, choose credible.
