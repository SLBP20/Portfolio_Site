# DESIGN_SYSTEM.md

## Overall style
Inspired by Eugene Yan:
- dark charcoal background
- soft off‑white text
- restrained blue accents
- editorial / reading-focused layout
- lots of whitespace
- strong typography
- thin dividers

## Personality requirement
The site must not feel robotic.
Add personality through:
- wording
- section titles
- project previews
- subtle visual touches

## Visual rules
- text-first design
- readable column width
- left-aligned content
- minimal card usage
- minimal shadows
- no neon gradients

## Approximate palette
Background: charcoal / near-black  
Primary text: warm off‑white  
Secondary text: muted grey  
Accent: medium blue  
Borders: soft grey

## Typography
- refined serif-style headings
- highly readable body font
- strong hierarchy

## Layout priorities
1. readability
2. credibility
3. scanability
4. speed
5. personality
